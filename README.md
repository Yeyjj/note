# 笔记

一个纯前端、本地优先的多形态笔记应用。打开浏览器就能用，所有数据保存在浏览器本地（IndexedDB），无需后端、无需注册、无需联网。

支持文本、手写、语音、思维导图、书籍、图表/公式六种笔记类型，内置 KaTeX 公式渲染、D3 图表、历史版本、文件夹分类、笔记加密、备份导出等能力。

## 特点

- 纯前端零后端：单个 HTML 入口，数据存 IndexedDB，可部署到任意静态托管，也可直接本地打开。
- 六种笔记形态：
  - 文本笔记（富文本编辑，支持标题、代码块、表格、待办、超链接、附件、公式、图表）
  - 手写笔记（Canvas 绘制，可选颜色/粗细，支持触屏与手写笔）
  - 语音笔记（浏览器录音，保存为音频，可回放）
  - 思维导图（拖拽节点、增删子节点、自动连线）
  - 书籍（封面、简介、分卷、章节管理）
  - 图表 / 公式（D3 生成 10 种图表；KaTeX 渲染行内与独立公式）
- 本地优先：所有笔记、附件、历史版本都存在浏览器本地，不上传任何服务器。
- 历史版本：每次保存生成快照，支持按数量或按天数保留，可预览、恢复、删除。
- 文件夹与分类：自定义文件夹颜色，支持按类型筛选、搜索、排序（更新时间/创建时间/标题/类型/字数/大小）。
- 笔记锁：为单条笔记设置密码（SHA-256 哈希），解锁后才能查看。
- 备份与恢复：一键导出 .notebak 备份包（ZIP，含全部笔记与附件），可完整导入恢复。
- 毛玻璃 UI：支持深浅色主题，毛玻璃强度可调，横屏与移动端适配。
- 回收站：删除的笔记保留 30 天，可恢复或彻底清除。

## 快速开始

方式一：直接打开

下载仓库后，用浏览器打开 index.html 即可。建议通过本地服务器访问，避免部分浏览器对本地文件的限制。任选一种命令启动本地服务：python3 -m http.server 8080，或 npx serve .，然后访问 http://localhost:8080。

方式二：部署到静态托管

把整个目录上传到 GitHub Pages、Cloudflare Pages、Vercel、Netlify 等任意静态托管即可，无需构建步骤。

## 使用说明

- 新建笔记：点击底部 + 新建文本笔记；长按 + 展开更多类型（语音、思维导图、手写、书籍）。
- 切换视图：右上角菜单可切换网格 / 列表 / 紧凑视图，以及排序方式。
- 搜索：点击搜索图标，输入关键词，支持标题与正文高亮。
- 文件夹：侧边栏「新建文件夹」，可自定义颜色；编辑模式可删除文件夹。
- 历史版本：笔记详情页右上角「⋯」→「历史版本」。
- 笔记锁：详情页「⋯」→「添加笔记锁」。
- 备份：设置页 →「数据与备份」→「导出备份 / 导入备份」。

## 数据存储

笔记、文件夹、历史版本均存储在浏览器 IndexedDB（数据库名 notes_db）。界面偏好（深浅色、毛玻璃强度、视图、排序、历史版本策略）存储在 localStorage。附件以 Blob 形式随笔记存储，导出备份时转为 Base64 打包进 ZIP。

注意：清除浏览器站点数据会导致笔记丢失，请定期使用「导出备份」保存 .notebak 文件。

## 技术栈

原生 HTML / CSS / JavaScript，无框架、无构建步骤；IndexedDB 存储；KaTeX 公式渲染；markdown-it 与 texmath；D3.js 图表；JSZip 备份打包；Canvas API 手写；MediaRecorder API 录音。

## 浏览器要求

推荐使用较新版本的 Chrome、Edge、Safari 或 Firefox。语音录音需要麦克风权限，部分功能依赖 MediaRecorder 与 IndexedDB 支持。

## 目录结构

根目录下：index.html 为入口；css/ 放样式（base、main、编辑器、弹窗）；js/ 放逻辑（db 数据库封装、state 全局状态、utils 工具函数、main 列表与侧边栏、editor-text 文本编辑器、editor-draw 手写、editor-voice 语音、editor-mind 思维导图、editor-book 书籍、detail 详情与历史、settings 设置与备份、app 文件夹与初始化）；lib/ 放第三方库。
